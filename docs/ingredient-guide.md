# 팀원 B: 성분 주의 가이드

## 등록 전 성분 확인 (2026-10-23)

- `GET /api/mypills/preview?type=MEDICINE|SUPPLEMENT&itemId=...`를 추가했다.
  기존 약장 조회와 같은 Authorization 헤더를 사용하며 해당 로그인 사용자의 약장만 비교한다.
- 응답: `type`, `itemId`, `itemName`, `alreadyRegistered`, `ingredientGuide`,
  `ingredientOverlaps`, `unverifiedCabinetItems`.
- 미리보기는 읽기 전용이며 제품·성분·약장·스케줄을 저장하지 않는다.
- 잘못된 분류/비양수 ID는 400, 없는 제품은 404를 반환한다.
- 직접 검색 등록과 사진 후보/OCR 선택 등록 모두 확인 화면을 거친다.
- 안내 조회 → 취소 또는 확인 → 기존 등록 API 순서다. 조회 실패·취소·화면 이탈 시 등록하지 않는다.
- 이미 등록된 제품만 선택되면 확인 화면의 등록 버튼을 비활성화한다.
- 가이드 누락과 기존 약장의 미확인 제품 수를 보여준다. 겹침 없음은 안전 판정이 아니다.
- 확인 중 폼 입력과 반복 등록 요청을 막아 선택 제품과 안내가 어긋나지 않게 한다.
- 미리보기는 조회 시점의 약장 상태다. 다른 화면/기기에서 이후 변경된 상태를 잠그지 않으며,
  실제 등록 시 기존 서버 중복 등록 검증이 계속 적용된다.
- OCR 여러 제품은 각 제품을 기존 약장과 비교한다. 이번 선택 제품끼리의 겹침은
  등록 후 약장에서 확인하도록 안내하며, 등록 전 일괄 상호 비교 기능은 포함하지 않는다.
- 실제 AI 모델/인식 결과를 변경하지 않고 등록 직전 UI 흐름만 확장했다.

검증: 실제 HTTP 테스트로 미리보기 무저장·타 사용자 약장 분리·이미 등록됨·미확인 상태·400/404를 확인했다.
Flutter는 취소/확인, 조회 실패 후 재시도, 이미 등록된 제품 차단, 응답 전 화면 이탈,
사진 인식 후보의 확인 후 등록 흐름을 검증한다.

## 성분 가이드 목록 추가 (2026-10-22)

- `GET /api/ingredient-guides`: 로그인 및 약품 등록 없이 5개 성분의 가이드와 명시적 별칭을 반환한다.
- 응답은 `[{ "guide": { ...기존 가이드 필드 }, "aliases": [ ...성분 별칭 ] }]` 형식이다.
- 약장 경고와 동일한 카탈로그를 사용해 문구·출처가 서로 달라지지 않도록 했다.
- 마이약장 상단의 ‘성분 가이드’ 버튼으로 목록을 열 수 있다.
- 목록을 한 번 받아 성분명·별칭을 검색한다. 검색은 부분 일치를 지원하지만,
  약품 성분 판정은 기존의 명시적 별칭 정확 일치 규칙을 그대로 유지한다.
- 각 항목을 펼치면 요약·상세 안내·출처 URL·자료 확인일이 표시된다.
- 검색 결과 없음과 연결 실패를 구분하고, 연결 실패 시 재시도할 수 있다.
- 이번 작업은 기존 안내를 조회하는 기능이며 의학적 문구나 성분 범위를 확대하지 않는다.
- 검증: 백엔드 전체 21개, Flutter 가이드·약장 관련 14개 테스트 통과.
  비로그인 HTTP 조회, 5개 가이드·별칭 응답, 별칭 검색, 상세 출처 표시, 빈 검색 결과, 실패 후 재시도를 확인했다.

## 성분 겹침 안내 추가 (2026-10-22)

- 약장 조회 응답 각 항목의 `ingredientOverlaps`에 같은 가이드 성분이 연결된 다른 제품을 반환한다.
- 각 항목은 `code`, `ingredientName`, `relatedItems`(등록 ID `regId`, 제품명 `itemName`)를 포함한다.
- 비교 범위는 기존 선정 성분 5개이며 표준 가이드 코드로 별칭을 통합한다.
- 한 제품의 중복 성분 행이나 동일 타입·동일 제품 ID의 중복 등록은 자기 제품과의 겹침으로 세지 않는다.
- 의약품과 영양제를 함께 비교한다. 서로 다른 타입의 동일 숫자 ID는 별개 제품이다.
- 카드에 ‘다른 제품과 성분 겹침 N건’을 표시하고 펼치면 해당 제품명을 보여준다.
- 검색·탭 필터와 관계없이 전체 약장 기준이며 삭제 성공 시 남은 카드의 안내도 즉시 갱신된다.
- 구버전 서버에서 필드가 없으면 안내를 숨긴다. 겹침 없음은 안전 판정을 뜻하지 않는다.
- 실제 동시 복용·과다복용을 판정하지 않고 함량을 합산하지 않는다.
- 기존 DB나 AI 서비스의 변경은 필요 없다.
- 검증: 백엔드 전체 20개 테스트 통과(기존 대체약 관련 테스트 포함),
  Flutter 가이드·약장 관련 11개 테스트 통과, 변경 Flutter 파일 정적 분석 오류 없음.
  HTTP 통합 테스트에서도 별칭으로 연결된 두 제품의 겹침 응답을 확인했다.

## 구현 범위

마이약장 `GET /api/mypills` 응답의 각 항목에 `ingredientGuide`를 추가했다.
의약품과 영양제 모두 저장된 성분 목록으로 판정한다.
가이드는 `medicine/guide/IngredientGuideService.java`의 버전 관리되는 고정 목록이다.
DB 스키마·기존 성분·사용자 약장 데이터 변경 및 외부 AI 호출은 없다.
팀원 A와 기준을 합의하면 이 서비스의 명시적 별칭 연결을 변경하면 된다.

| 성분 | 분류 | 공식 근거 |
|---|---|---|
| 칼슘 | 과다섭취 주의 | https://ods.od.nih.gov/factsheets/Calcium-Consumer/ |
| 비타민 C | 과다섭취 주의 | https://ods.od.nih.gov/factsheets/VitaminC-Consumer/ |
| 아세트아미노펜 | 중복복용·간손상 주의 | https://www.fda.gov/drugs/safe-use-over-counter-pain-relievers-and-fever-reducers/acetaminophen |
| 마그네슘 | 과다섭취 주의 | https://ods.od.nih.gov/factsheets/Magnesium-Consumer/ |

자료 확인일: 2026-10-20. 위 자료를 한국어로 요약한 일반 교육용 안내다.
국내 개별 제품 허가사항을 검증한 안내나 개인별 복약 판단이 아니다.
투여 경로·연령·제형별 용량은 제시하지 않는다.
등록 여부로 오남용·의존·중복복용 발생을 진단하지 않는다.
함량 합산, 원소량 환산, 복용 기록 기반 판정, 푸시 알림은 이번 범위에 포함하지 않는다.

## 연결 규칙

- 성분 ID 하드코딩 없이 성분명과 명시적 별칭을 정확히 비교한다.
- 유니코드 NFKC, 대소문자, 공백만 정규화한다.
- 제품명, 부분 문자열, 괄호 제거, 숫자/함량 제거를 이용한 추측 매칭은 하지 않는다.
- 칼슘이 포함된 다른 의약품 염, 스테아르산마그네슘 같은 첨가제를 영양성분으로 오인하지 않는다.
- 같은 가이드의 여러 별칭은 약품 한 개 내에서 한 번만 반환한다.
- 복합제는 연결된 가이드를 모두 반환하고 미확인 성분도 함께 표시한다.
- `AVAILABLE`은 입력된 모든 성분이 이 목록에 연결되었다는 뜻이며 모든 위험을 검사했다는 뜻이 아니다.

## 응답 예

```json
{
  "ingredientGuide": {
    "status": "PARTIAL",
    "warnings": [{
      "code": "ACETAMINOPHEN",
      "ingredientName": "아세트아미노펜",
      "riskType": "DUPLICATE_USE",
      "title": "중복복용·간손상 주의",
      "summary": "감기약·진통제에 같은 성분이 있는지 확인하세요.",
      "detail": "실제 응답은 카탈로그의 전체 안내 문구를 포함합니다.",
      "sourceName": "FDA · Acetaminophen",
      "sourceUrl": "https://www.fda.gov/drugs/safe-use-over-counter-pain-relievers-and-fever-reducers/acetaminophen",
      "reviewedAt": "2026-10-20"
    }],
    "unmatchedIngredients": ["카페인"]
  }
}
```

상태: `AVAILABLE`, `PARTIAL`, `NO_REGISTERED_GUIDE`, `NO_INGREDIENT_DATA`.
구버전 서버가 필드를 보내지 않으면 Flutter는 `UNAVAILABLE`로 처리한다.
어느 상태도 안전 판정으로 표현하지 않는다.

### 실제 DB의 시연 후보

아래는 기존 DB 연결 확인 결과이며 최신 허가·판매 상태 또는 원본 성분표 검증을 뜻하지 않는다.
영양제 원료와 기능성 성분의 구분도 팀원 A의 원본 데이터 대조가 필요하다.

| 성분 | DB 제품명 | 구분 | 현재 itemId | 품목코드 |
|---|---|---|---:|---|
| 칼슘 | 에이드칼슘 | SUPPLEMENT | 27 | 2004001516210 |
| 비타민 C | 지근억비피더스 | SUPPLEMENT | 3 | 200400150703 |
| 마그네슘 | 솔빛M | SUPPLEMENT | 66 | 2004001508383 |
| 아세트아미노펜 | 써스펜데이정 | MEDICINE | 501 | 201504949 |

에이드칼슘은 동일 칼슘 연결이 2행 조회된다. B의 가이드는 코드별로 중복 제거하지만
원천 연결 중복 정리는 A의 DB 수정 범위에 포함해야 한다.
써스펜데이정은 [약학정보원](https://www.health.kr/drug/2015072100003?view=inter)에
취소일이 표시되어 있어 현재 판매 제품 시연 후보로 확정하지 않는다.
의약품안전나라 해당 품목 상세는 이번 조회 도구로 열리지 않아 공식 상태 확인은 남아 있다.

다른 환경에서는 itemId가 달라질 수 있다. 동봉한 `ingredient-guide-demo-audit.sql`을 읽기 전용으로
실행해 품목코드와 현재 ID를 다시 확인한다.

### 모르핀 연결 후보 확보

[식약처 의약품안전나라 공식 제품 정보](https://nedrug.mfds.go.kr/pbp/CCBBB01/getItemDetail?itemSeq=199704619)에서 확인:

- 제품: 엠에스알서방정30밀리그램(모르핀황산염수화물)
- 품목기준코드: `199704619`
- 업체: 하나제약(주)
- 주성분: 모르핀황산염수화물, 1정 중 30밀리그램
- 현재 가이드의 명시적 별칭 `모르핀황산염수화물`로 `MORPHINE` 연결 가능.
- 공식 주의사항의 의존성, 호흡억제, 중추신경억제제·알코올 병용 위험은 현재 일반 안내와 부합.

주성분 염의 30mg을 모르핀 자체의 원소량처럼 환산하거나 기존 `모르핀` 행에 함량만 복사하지 않는다.
제품·성분 원본과 수집 규칙을 A와 확정한 뒤 해당 품목을 기존 수집 경로로 반영한다.
이번 작업에서는 개발 DB에 임의 제품을 생성하지 않았다.

### 팀원 A/C 전달 사항

- A: 손상된 성분명, 첨가제 혼입 여부, 칼슘 중복 연결, 모르핀 품목 수집,
  써스펜데이정 허가 상태를 확인한다. 성분명·ID 병합 후 이 테스트를 다시 실행한다.
- C: 준비한 이미지의 품목코드를 먼저 확정하고 해당 환경의 itemId와 연결한다.
  인식 결과 → 사용자 확인 → 약장 등록 → 약장 조회의 `ingredientGuide` 표시로 이어져야 한다.
- 현재 확인한 AI `python_service`에는 고정 결과용 데모 분기를 찾지 못했다.
  C의 데모 이미지·고정 결과 계약이 준비되어야 이미지부터 시작하는 통합 리허설이 가능하다.
- 이 세션에는 연결된 브라우저가 없고 인앱 브라우저 생성도 불가능했다.
  실제 브라우저에서의 시각적 리허설은 완료로 간주하지 않는다.
  Flutter 화면 테스트는 가짜 API를, HTTP 통합 테스트는 실제 서버와 H2를 사용한다.

추가 실행 명령:

# safepill_fe: 가이드 및 마이약장 화면 흐름
